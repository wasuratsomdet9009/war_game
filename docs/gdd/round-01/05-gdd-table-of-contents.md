## 1. แม่แบบรายระบบ (หัวข้อ 117) — ทุกบทระบบต้องใช้

### 1.1 หัวข้อบังคับ 12 ข้อ

ทุก "ระบบ" ในบทใดก็ตาม ต้องมีครบ 12 หัวข้อนี้ตามลำดับ ในส่วนอื่นของเอกสารนี้จะอ้างถึงว่า **"แม่แบบ T1–T12"**

| รหัส | หัวข้อ (117) | สิ่งที่ต้องเขียน | รูปแบบที่แนะนำ |
|---|---|---|---|
| T1 | **วัตถุประสงค์** | ระบบนี้มีไว้ทำไม สนับสนุนเสาหลักข้อใดใน 0.3 (ด่านคัดฟีเจอร์) | 2–4 ประโยค + รายชื่อเสาหลัก |
| T2 | **กลไกการทำงาน** | กติกา สถานะ สูตร และลำดับเหตุการณ์ ตัวเลขทุกตัวเป็นค่าตั้งต้น | ตารางสถานะ, สูตรแบบข้อความ, แผนภาพข้อความ |
| T3 | **ข้อมูลนำเข้า** | ใช้ข้อมูลอะไรจากระบบใดหรือจาก OSM | ตาราง: ข้อมูล / มาจาก / ความถี่ในการอัปเดต |
| T4 | **การตัดสินใจของ AI** | AI ชั้นใด (Faction / Commander / Unit / Civilian / Convoy / Mercenary) ตัดสินใจอะไร ด้วยเทคนิคใด (15.2) และ LLM มีบทบาทเฉพาะงานภาษาหรือไม่ | ตาราง: ชั้น AI / การตัดสินใจ / เทคนิค |
| T5 | **ผลลัพธ์** | ระบบนี้ส่งอะไรออกไป | รายการ |
| T6 | **ความเชื่อมโยงกับระบบอื่น** | ส่งผลต่อและได้รับผลจากระบบใด อ้างอิงลูกศรใน [02 System Map](02-system-map.md) | ตาราง: ระบบ / ทิศทาง / สิ่งที่ไหล |
| T7 | **ตัวอย่างการเล่นจริง** | เหตุการณ์จริงในเกม ควรโยงกับ Scenario A–D (109–112) | เรื่องเล่าสั้นแบบเป็นขั้น |
| T8 | **Echelon ที่เกี่ยวข้อง** | ยุทธศาสตร์ / ยุทธการ / ยุทธวิธี / หลายระดับ และช่วงซูม Z ที่แสดงผล (105.3) | ตารางเล็ก |
| T9 | **ข้อมูลที่ต้องเก็บ (Data Model)** | โครงสร้างข้อมูลหลักในระดับแนวคิด ไม่ใช่โค้ด | ตาราง: Entity / Field / ความหมาย / บันทึกใน Save หรือไม่ |
| T10 | **ระยะพัฒนา** | Prototype / MVP / Vertical Slice / Full Vision ว่าเริ่มเมื่อไรและครบเมื่อไร ต้องสอดคล้องกับตาราง Module × Phase ใน [04 แผนพัฒนา ส่วนที่ 8](04-phased-roadmap.md) | ตาราง: ระยะ / สิ่งที่มีในระยะนั้น |
| T11 | **ผลต่อประสิทธิภาพบน Mac M4** | ภาระ CPU, GPU และหน่วยความจำ เทียบกับงบใน 106 และวิธีลดภาระ | ตาราง: ทรัพยากร / ภาระ / วิธีลด |
| T12 | **การแสดงผลในสไตล์ Neon** | Color Token (96.1–96.2), รูปทรงและลวดลายที่เข้ารหัสซ้อน (97), ระดับซูมที่แสดง ต้องอ่านได้จากมุมบน (0.6) | ตาราง: สิ่งที่แสดง / Token / รูปทรง/ลาย / ช่วงซูม |

### 1.4 กติกาการเขียนที่ใช้กับทุกบท

1. ถือหัวข้อ 0.6 และ 108.1 เป็นข้อยุติ: มุมมอง Top-down ที่ซูมต่อเนื่อง, อาคาร 2.5D, ภายในอาคารเป็น Floor Plan Overlay, macOS บน MacBook Pro M4 Pro 24 GB, Native ARM64 + Metal
2. ทุกตัวเลขเป็นค่าตั้งต้นที่ต้องวัดหรือทดสอบ
3. ไม่ลดรายละเอียดของสเปกโดยไม่มีเหตุผล ถ้าเปลี่ยนหรือตัดสินใจอะไร ให้บันทึกในส่วน "การตัดสินใจในบทนี้"
4. ปฏิบัติตามหลักจริยธรรม 101 ทุกบท
5. ไม่ตัดตารางกลางทาง และไม่เขียนโค้ด
6. ใช้หมายเลขหัวข้อของสเปก (เช่น "50.1") เมื่ออ้างถึงสเปก และใช้ลิงก์สัมพัทธ์เมื่ออ้างถึงบทอื่น
